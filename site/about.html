About VIZIER

What is this?

A living, public knowledge graph — a personal mastery roadmap built around learning NODES, not days. Universe 01 covers frontier AI engineering: 202 planned nodes across 10 domains, each a concept, build, or synthesis worth genuinely understanding. Some nodes take an hour; some take days. Progress is measured in light, not time.

The Node Protocol

A node lights up only when its note contains a Feynman explanation that a 12-year-old could follow, and (for build nodes) an artifact that actually runs. Notes are dynamically wikilinked; the knowledge graph automatically rewires nightly based on their relationships.

Immutable Past, Fluid Future

Once a node is lit, it is locked forever. Ghost nodes represent planned topics for plan v1.0.0, which can be revised through human-approved replans. Every revision is publicly logged in the repository changelog. Transparency about plan adaptations is a core feature of the system.

The Three States

The learning roadmap is tracked across three distinct states:

Ghost: Planned knowledge node, currently unlit.
Charging: Node is currently in progress, pulsing.
Lit: Note is completed, Feynman-tested, and locked forever.

Universes

VIZIER is a generational engine. Each complete mastery graph is a Universe. This is UNIVERSE 01 — AI ENGINEERING. When its final node lights, Universe 01 is archived forever — every note, every lock, every changelog entry preserved read-only — and Universe 02 begins with a fresh graph. The field moves at exponential speed; the machine is built to begin again.

The Frozen Engine

Inside the repository sleeps a complete agentic lab system (including supervisor, memory, RAG, approval gate, and injection scanner)—built agentically, but deliberately frozen. A floating milestone called THE RESURRECTION will bring the system back online, deployed manually. Until then, it serves as the master textbook.

Honest Limits

Charging nodes are shown honestly as charging. Lit nodes are locked — there is no editing history to make the journey look smoother than it was. Ghost nodes are a plan, and plans change: every revision is logged publicly.
